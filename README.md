# Refine

**Refine** is an offline-first workout tracking application built with **.NET MAUI Blazor Hybrid**. It helps users manage training programs, track workout performance, monitor recovery, and analyze body composition—all from a single mobile application.

## Features

* 📋 Create and manage workout programs
* 💪 Track sets, reps, weight, and RIR
* 📈 Monitor strength progression and performance trends
* 🧠 Calculate CNS and muscle fatigue
* 🔥 Track training streaks and consistency
* ⚖️ BMI and body fat analysis
* 📱 Fully offline experience with local data storage

## Tech Stack

* **.NET MAUI**
* **Blazor Hybrid**
* **SQLite**
* **C#**

## Architecture

```text
Blazor UI
    ↓
Service Layer
    ↓
Business Logic
    ↓
SQLite Database
```

## Key Highlights

* Offline-first architecture
* Recovery and fatigue tracking system
